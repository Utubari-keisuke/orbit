# Orbit

感情が軌道になる、わたしの宇宙。言葉を星にして、他者の軌道と交差させる Web アプリです。

- フロント: Vite + React + TypeScript + Three.js
- バックエンド: Supabase（ログイン、星の保存、他者の Orbit の取得）。自前のサーバーは要りません
- デプロイ: Vercel など、静的ホスティング

## まず動かす（Supabase なし）

```bash
npm install
npm run dev
```

`.env` が無いときは **ローカルモード** で動きます。ログインは不要で、記録はそのブラウザにだけ保存され、他者の軌道はデモ用の仮想データです。

## 本物にする（Supabase あり）

1. [Supabase](https://supabase.com) でプロジェクトを作る
2. SQL Editor で `supabase/schema.sql` を丸ごと実行する（テーブル、RLS、関数が入ります）
3. Authentication > Providers で **Email** を有効にする（パスワード無しの「マジックリンク」を使います）
4. Authentication > URL Configuration の **Site URL** と **Redirect URLs** に、公開先の URL と `http://localhost:5173` を入れる
5. `.env.example` を `.env` にコピーし、Project Settings > API の URL と anon key を入れる
6. `npm run dev`

anon key は公開されても構いません。守っているのは、`schema.sql` の行レベルセキュリティ（RLS）です。service_role key は絶対に `.env` やフロントに入れないでください。

## 他者の Orbit が見える条件

`random_orbit()` が、次の条件を満たす相手を 1 人、ランダムに返します。

- 公開中で、自分ではない
- 直近 30 日以内にログインしている
- 星が 1 つ以上ある
- 自分が通報した相手ではない

返すのは、匿名の番号（例 `#4821`）と、新しい順に最大 4 つの星の「言葉と色」だけです。メールアドレスや user_id は返しません。ブラックホールの星は共有しません。

## 安全面の設計

| 項目 | 実装 |
| --- | --- |
| 自分の星 | RLS で本人だけが読み書きできる |
| 非公開 | `profiles.is_public = false` で、自分も他者の候補から外れ、星も見えなくなる |
| 通報 | `reports` に保存。通報した相手は以後、その人には表示されない |
| 同意 | ログイン画面で、言葉と色が匿名で表示されることへの同意を必須にしている |
| データ削除 | ログの「星とログをすべて消す」で、星と交差ログを削除する |

## 未対応のこと（次にやること）

- **通報の確認画面。** 通報は保存されますが、運営が見る管理画面はありません。Supabase のテーブルビューで確認してください
- **投稿内容のチェック。** 他者に見える「言葉」に、不適切な内容を弾く仕組みがありません。公開前に、禁止語の判定か、AI による確認を入れてください
- **アカウント削除。** データの削除はできますが、ログインアカウント自体の削除は未実装です
- **相手側の履歴。** 交差・回避は、自分のログにだけ残ります。相手の宇宙には影響しません
- **年齢確認。** 主な対象が 16〜22 歳のため、公開前に利用規約・プライバシーポリシー・年齢の扱いを決めてください

```
src/lib/util.ts          言葉 → 色・軌道の決め方
src/App.tsx              画面と、遭遇のしくみ
```
